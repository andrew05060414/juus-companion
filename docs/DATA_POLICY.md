# 数据、隐私与开源政策

> 创建日期：2026-09-27 ｜ 最后更新：2026-09-27 ｜ 版本：v0.1

本项目从第一天起按"未来会公开"的标准开发。以下规则对人和 AI Agent 同样有效，违反即视为 PR 不合格。

## 1. 永远不进仓库的内容

| 类别 | 例子 | 放在哪里 |
|---|---|---|
| 游戏原始素材 | 台词原文、剧情文本、啾信/JUUs 原文、语音音频、立绘、头像、Live2D、BGM | 部署者本地数据目录（`data/`，已 gitignore） |
| 由游戏素材生成的产物 | 角色卡、世界书、示例对话、原声索引 | 同上，或私有存储 |
| 同人素材 | B 站视频提取的剧本（PX-406） | 私有存储，仅个人使用 |
| 个人数据 | Chronicle 检索结果、聊天记录、长期记忆、人设成长记录 | 服务端数据库 / 私有存储 |
| 密钥与身份 | API Key、令牌、Cookie、推送凭据、`google-services.json`、签名文件 | 环境变量 / 私有配置，仓库只放 `*.example` |
| 部署细节 | 真实 IP、域名、Tailscale 地址、NAS 路径 | 私有部署配置 |

仓库里只允许：代码、导入与生成脚本、模板、测试（使用**自造**的假数据）、文档、以及**不含任何游戏原文**的示例卡。

## 2. 自动检查（CI 必须实现）

- 密钥扫描（如 gitleaks），发现即失败。
- 禁止提交音频、图片、Live2D、大体积 JSON 数据文件到非白名单目录。
- 测试数据只能使用虚构角色与虚构台词。

## 3. 上游数据源

| 来源 | 内容 | 许可 | 用法 |
|---|---|---|---|
| AzurLaneTools/AzurLaneData | 游戏配置表（五服） | 无 | 本地拉取，不再分发 |
| Fernando2603/AzurLaneData | 配置表（EN，更新快） | 无 | 同上 |
| Fernando2603/AzurLane | 语音音频、图片资源（EN） | 无 | 同上 |
| AzurLaneTools/AzurLaneLuaScripts | 原始脚本 | 无 | 仅在 JSON 缺字段时参考 |
| oneroomlife/blyy | Android 客户端代码 | GPL-3.0 | fork 到 `app-android/`，保留版权与许可 |
| blacktunes/juus-maker | 啾信截图生成器 | 无许可证 | **只参考界面，不复制任何代码或资源** |

## 4. 名称与声明

- 项目名、图标不使用"碧蓝航线"官方名称与标志。
- README、App 关于页、宣传视频均注明"非官方同人项目，与官方无关"。
- 不提供声优声音克隆功能。

## 5. 开源发布前检查（M6）

1. 全量历史扫描：素材、密钥、个人数据、真实地址。
2. 如历史中曾出现不该公开的内容，以清理后的新历史发布。
3. 文档中的截图、演示不出现个人隐私内容。
4. Andrew 最终批准后才将仓库设为公开。
