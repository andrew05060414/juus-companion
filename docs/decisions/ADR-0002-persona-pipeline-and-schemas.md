# ADR-0002：人设流水线分层架构与多目标导出中间规范

> 创建日期：2026-09-27 ｜ 最后更新：2026-09-27 ｜ 版本：v1 ｜ 状态：提议（待 Andrew 审查批准）

## 背景

啾信陪伴机器人的核心效果依赖于舰娘人设质量与世界观一致性。游戏原始解包数据包含 304 个啾信话题、9165 句私聊对白、2485 套皮肤语音与 6879 段剧情对白。为了实现可批量运行、高一致性且符合开源数据红线（数据永不进仓库）的人设工程，需要确立流水线分层架构、世界书分层机制与多端导出格式规范。

## 决策

1. **流水线五层解耦架构**：
   - **导入层（Fetcher）**：从 `docs/DATA_POLICY.md` 指定的公开上游拉取解包表至本地 `data/raw/`（已 gitignore），记录版本指纹与 SHA256 `manifest.json`，支持离线/缓存运行；
   - **抽取层（Extractor）**：按角色汇总啾信、JUUs 动态、语音台词、档案与剧情，执行变体合并规则（约克城 = 约克城 + 约克城II；META 保持独立；缺 CN 数据时自动降级 EN 并标注待补）；
   - **生成层（Generator）**：以 OpenAI 兼容模型网关或内置确定性高保真引擎构建 SillyTavern V2 规范卡片；
   - **质检层（Validator）**：自动执行 6 大检查规则（称呼规范、禁忌词/AI出戏、口癖特征、原始一致性、誓约基线、ST V2 规范），输出结构化 JSON 与 Markdown 质检报告；
   - **导出层（Exporter）**：同源导出 SillyTavern V2、独立世界书、AstrBot 人格 JSON 以及啾信大脑中间规范。

2. **三层世界书（Lorebook）体系**：
   - **L0 母港通用（Port Common）**：指挥官领导权、心智魔方与舰装原理、海域巡逻与塞壬防务、誓约之戒与满好感羁绊（全员共享）；
   - **L1 阵营特色（Faction）**：铁血（严谨与生物机械）、白鹰（自由协作与航母编队）、重樱（神道古风与定海结界）、皇家（骑士精神与红茶）、META（余烬执念）；
   - **L2 角色专属（Character Specific）**：生活爱好、健康督促管理、人际纽带羁绊、战斗舰装、誓约深情哲学。

3. **关系基线与扩展状态**：
   - 所有角色默认处于**已誓约 + 好感 200 + 满级（125）**状态；
   - 在卡片扩展字段预留 `game_state`，预留真实游戏练度/皮肤导入能力。

4. **啾信大脑中间格式（Juus Brain Format）**：
   - 在 Issue #3 大脑形态技术验证定稿前，确立包含角色元数据、SillyTavern 人格定义、三层世界书、原始素材统计与誓约基线的统一中间 JSON 格式。

## 后果

- **优点**：一条命令即可全自动从零运行完素材提取、角色卡生成、自动质检与多格式交付；完全满足数据政策（生成物存放在私有本地目录，测试严格使用自造假数据）。
- **风险与局限**：首批生成的角色卡需经 Andrew 抽样试聊与主观语气检验；模型网关离线时自动切换确定性高保真模板模式。
