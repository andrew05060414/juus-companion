# ADR-0001：单一仓库、许可证与数据边界

> 创建日期：2026-09-27 ｜ 最后更新：2026-09-27 ｜ 版本：v1 ｜ 状态：已接受（Andrew，2026-09-27）

## 背景

项目包含服务端、数据流水线、Android 客户端、PWA 与部署配置，计划开源。Android 客户端计划基于 GPL-3.0 的 oneroomlife/blyy 修改；服务端可能以 AstrBot（AGPL-3.0）插件形态存在。游戏素材版权归官方所有。

## 决策

1. 暂时使用**单一仓库**（monorepo），按目录划分组件。
2. 许可证：仓库默认 **AGPL-3.0**；`app-android/` 为 **GPL-3.0**（继承 blyy）。Andrew 对许可证无偏好，优先考虑复用与速度。
3. 游戏素材及其衍生产物、个人数据、密钥**永不进入仓库**（见 `docs/DATA_POLICY.md`）。
4. 开发期仓库为**私有**，M6 发布审计通过后再公开。

## 后果

- 可直接复用 blyy 的界面与群聊、语音能力，不需要从头写 Android 客户端。
- 他人基于本项目提供网络服务时需开源其修改（AGPL）。
- 使用者必须自行运行导入脚本获取素材；README 与部署文档需写清楚步骤。
