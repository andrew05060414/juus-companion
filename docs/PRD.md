# 产品需求（PRD）

> 创建日期：2026-09-27 ｜ 最后更新：2026-09-27 ｜ 版本：v0.1
> 来源：Andrew 在 Multica 对话中的决策（2026-09-27），以及 Multica 任务 PX-402（人设调研）、PX-404（渠道与技术方案）、PX-406（B 站剧本调研）。

## 1. 一句话

做一群像真人一样**主动找你**、**记得你**、**性格各异**的碧蓝航线舰娘聊天伙伴：每位舰娘都是独立成员，能单聊，也能在小群里互相接话；重要消息**必达**，所有对话**可回看**。

## 2. 用户与使用场景

- 主要用户：Andrew 本人（私人使用），之后开源给其他指挥官自部署使用。
- 主力设备：三星 Galaxy Z Fold 7（Android，带 Google 服务，人在美国），另有 iPhone。
- 典型场景：
  1. 早上被列克星敦叫醒，晚上胡滕提醒刷题；她们记得昨天聊过什么。
  2. 在"白鹰小群"里说一句话，约克城、列克星敦接着聊，互相吐槽。
  3. 刷 JUUs 动态，看到武藏发了新帖、狮在下面评论，还 @ 了你。
  4. 在微信里随手和胡滕聊（保留现有 AstrBot 通道）。

## 3. 已确认的决策

| 主题 | 决策 |
|---|---|
| 群聊形态 | 每位舰娘在群里是**独立成员**（独立身份与头像）。不用"同一个账号加名字前缀"，也不去各 IM 多注册账号 → 自建客户端 |
| 群规模 | 以小群（2~6 人）为主，不做大群 |
| 主动程度 | 初期偏频繁；可按角色、按类型（提醒/闲聊/动态/早晚安）单独关闭，有免打扰时段 |
| 平台 | Android 原生优先；iPhone 用 PWA（后续） |
| 提醒 | 走手机系统通知，必须送达；App 内可看到完整历史 |
| 人设格式 | SillyTavern 角色卡（V2/V3）+ 世界书（Lorebook）；以官设为底，可成长、可手动修改；成长改动需经审阅、可回滚 |
| 关系基线 | 全员默认**已誓约 + 好感 200 + 满级**，不做好感分级；预留从游戏导入真实状态的字段 |
| 角色范围 | 最终覆盖全部角色（JUUs 中出现约 632 个）；分批推进，首批 8 个 |
| 首批角色 | 乌尔里希·冯·胡滕、腓特烈大帝、武藏、列克星敦、约克城（含约克城II，同一人）、狮、海伦娜·META、虎（HMS Tiger） |
| 微信 | 保留 NAS 上 AstrBot + 官方 ClawBot 的胡滕单聊；微信不承担群聊与必达提醒 |
| 记忆 | 复用个人记忆体系（Chronicle：AgentsView 为主、HSTRY 为备份；Mnemosyne 长期记忆），作为可选模块 |
| 开发方式 | AI 主导开发，Andrew 只在停止点验收与跟踪进度 |
| 开源 | 写完后开源并做视频宣传；许可证 AGPL-3.0（服务端等）+ GPL-3.0（Android，继承 blyy）；游戏素材一律不进仓库 |

## 4. 功能范围

### P0（第一个可用版本）
- 8 位首批舰娘可独立单聊；流式回复；重新生成。
- 主动消息：按角色/类型的频率、每日上限、随机时间窗、免打扰；舰娘可自己创建提醒（如"明天 8 点叫你"）。
- 必达推送：FCM 为主，NAS 自建 ntfy 兜底；服务端消息账本 + 客户端确认 + 重试；打开 App 按游标补齐，无重复。
- 历史：服务端为真源，客户端本地缓存，断网可看。
- 记忆：短期上下文 + 每角色长期记忆 + 可选的个人档案检索（Chronicle）。
- 折叠屏适配：展开双栏（会话列表 + 聊天），合上单栏。
- 安全：单用户账号、设备管理、客户端不保存任何模型/后台密钥。

### P1
- 小群聊天：导演决定谁接话，每轮 1~3 人发言，可不插话（`[SKIP]`），防止角色间无限互聊。
- JUUs 动态流：角色定时发帖、互相评论、@指挥官，并作为主动触达的一种形式。
- 第 2 批角色（有啾信私聊的 95 位）。
- iPhone PWA。

### P2
- 第 3、4 批角色（约 540 位 + 变体/新角色自动补）。
- 聊天中插播原声语音（日配原声，按关键词/概率）。
- 从游戏导入真实练度/皮肤/誓约状态。
- Live2D / 动态立绘。
- 同人剧本素材（B 站，见 PX-406，仅私用）。
- 自我进化（提案式：角色提出需求 → AI 工程师实现 → Andrew 批准）。

### 明确不做（当前）
- 公开注册、多用户 SaaS。
- 在公开仓库分发任何游戏素材或生成的角色卡。
- 声优声音克隆。
- 绕过任何平台（微信、B 站等）的限制或风控。

## 5. 成功标准（第一个可用版本）

1. 8 位舰娘在 App 中可独立单聊，说话风格能被 Andrew 认出"像她"。
2. 连续 7 天使用中，主动消息与提醒全部到达（锁屏、断网恢复、重启后），无丢失、无重复。
3. 舰娘能自然引用过去聊过的内容与 Andrew 的个人背景，不编造。
4. Andrew 可在设置里逐角色关闭主动消息、设置免打扰。
